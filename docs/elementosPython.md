# Elementos de Python

## Introducción

En este apartado se documenta el código fuente de la aplicación lavadero de coches.

La aplicación está formada por los archivos:

- ***lavadero.py***
- ***main_app.py***

## Archivo ***lavadero.py***

Este archivo contiene la clase principal *Lavadero*, encargada de simular el funcionamiento de un lavadero automático de vehículos.

Esta clase control el estado del lavadero, las opciones de lavado, los ingresos obtenidos y las diferentes fases por la que pasa cada lavado.

En el código se han identificados los siguientes elementos:

- Clase.
- Constructor __init__
- Atributos de instancia.
- Constantes.
- Métodos.
- Condicionales.
- Excepciones.
- Buckes.
- Listas.



## Archivo ***main_app.py***

El archivo main_app.py actual como el programa principal de la aplicación.

Su función es crear una instancia de la clase ***Lavadero*** y ejecutar diferentes simulaciones de lavado.

Durante la ejecución se muestran por pantalla las distintas fases del lavado, las opciones seleccionadas y los ingresos generados.

En el código se han identificado combinaciones de opciones:

- Lavado sin extras.
- Lavado con prelavado.
- Lavado con secado a mano.
- Lavado con encerado.
- Lavado con varias opciones combinadas.
