# Unidad 1 - Tarea R1

## Introducción

En esta tarea se analiza, ejecuta, depura y prueba una aplicación en Python que simula el funcionamiento de una lavadero.

En la tarea se debe trabajar aspectos relacionados con:

- Comentarios y documentaciń del código fuente.
- Ejecución y depuración desde Visual Studio Code.
- Pruebas unitarias con Python.
- Ejecución en entorno controlado o sandbox.
- Reflexión sobre la seguridad en distintos lenguajes de programación.
